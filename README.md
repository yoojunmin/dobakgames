# RISK Roulette Club

Render용 실시간 웹 멀티플레이 게임입니다. Node.js와 Socket.IO로 매칭과 게임 상태를 관리합니다.

## Render 배포

1. 이 폴더를 GitHub 저장소에 올립니다.
2. Render에서 **New + → Web Service**를 선택하고 저장소를 연결합니다.
3. `render.yaml`을 Blueprint로 적용하거나 다음 값을 입력합니다.
   - Build command: `npm install && npm run build`
   - Start command: `npm start`
4. 배포 후 `/health` 응답이 `{ "ok": true }`인지 확인합니다.

## 규칙

- 매칭은 최대 30초 동안 진행되며 4명이 모이면 바로 시작합니다. 30초에 2명 이상이면 시작합니다.
- 플레이어는 HP 100, 코인 1,000으로 시작합니다.
- 자기 차례에 카드 한 장을 뽑고 룰렛을 돌립니다. 방어권은 공격을 한 번 막고, 행운의 지갑은 200/300/500 코인을 더하며, 응급 키트는 HP를 15 회복합니다.
- 룰렛은 본인에게 15 또는 30 피해를 주거나, 임의의 상대에게 15 또는 25 피해를 줍니다.
- HP가 0 이하가 되면 탈락하고 마지막 생존자가 승리합니다.

현재 룸과 플레이어 상태는 서버 메모리에 저장됩니다. Render에서 여러 인스턴스를 쓰거나 재시작 후에도 방을 유지하려면 Redis 같은 공유 저장소를 연결해야 합니다. 이 게임의 코인은 게임 안에서만 쓰이는 가상 포인트입니다.
